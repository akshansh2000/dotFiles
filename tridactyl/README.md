# tridactyl

Catppuccin Mocha theme for Tridactyl, generated from the same
`~/.config/theme/colors.sh` as waybar / rofi / foot / yazi / the startpage.

    themes/catppuccin.css.tmpl   <- edit this
    themes/catppuccin.css        <- generated by ~/.config/theme/apply-theme.sh

## Applying it

Tridactyl does not read the file live — it **snapshots the CSS into extension
storage**. So a change is two steps: regenerate, then re-fetch.

    ~/.config/theme/apply-theme.sh

then, in Firefox:

    :colourscheme --url http://127.0.0.1:8123/tridactyl-catppuccin.css --update catppuccin

`--update` is what forces the re-fetch; without it Tridactyl keeps the copy it
already has. `apply-theme.sh` prints this line as a reminder.

The URL works because `~/.config/startpage/tridactyl-catppuccin.css` is a
symlink to `themes/catppuccin.css`, and the startpage's darkhttpd serves it
(verified: `200`, symlink followed). No native messenger needed — this is the
whole reason for going through the URL rather than the file.

## Native messenger — what `:installnative` actually does

It **installs nothing itself.** It prints a shell command for you to paste into
a terminal, roughly:

    curl -fsSl https://raw.githubusercontent.com/tridactyl/native_messenger/master/installers/install.sh \
      -o /tmp/trinativeinstall.sh && sh /tmp/trinativeinstall.sh <TAG>

Run `:installnative` to get the line with the right `<TAG>` filled in rather
than guessing it.

That script fetches a **precompiled Nim binary** and writes a native-messaging
host manifest so Firefox is allowed to launch it. What it buys:

- `~/.config/tridactyl/tridactylrc`, sourced at startup — the actual goal.
- `:loadtheme`, `:source`, `:editor` (edit a textarea in `$EDITOR`), `:!`,
  and reading/writing files generally.

**The trade.** The whole point of the native messenger is that a web extension
gets to run programs on the machine. The installer pipes a remote script into
`sh` and drops a binary that Firefox can then invoke. That is not a reason to
avoid it — it is the officially supported path and it is what every Tridactyl
user with an rc file is running — but it is a real trust decision, so it is
worth making deliberately rather than by reflex.

If a prebuilt binary is the part you dislike, there is an older Python
implementation at
<https://github.com/tridactyl/tridactyl/tree/master/native> (`install.sh`) —
slower, but a script you can read start to finish before running it.

### Gotcha on this machine

This profile lives at `~/.config/mozilla/firefox/…`, **not** `~/.mozilla`.
Native-messaging manifests are conventionally installed to
`~/.mozilla/native-messaging-hosts/`. After running the installer, check:

    ls ~/.mozilla/native-messaging-hosts/ ~/.config/mozilla/native-messaging-hosts/

and confirm with `:native` in Firefox. If Tridactyl reports the native
messenger as missing, the manifest is probably in the one Firefox is not
reading — symlink it across rather than reinstalling.

### Once it is installed

    :loadtheme catppuccin
    :colourscheme catppuccin

`:loadtheme` reads `<dir of tridactylrc>/themes/<name>.css`, which is exactly
where `catppuccin.css` already lives, so no files need moving. At that point the
`--url` route above becomes optional.

## What the colours map to

| Element | Colour |
|---|---|
| command line, mode indicator bg | mantle |
| completions bg | base |
| selected completion row | mauve bg, base text |
| hint labels | yellow bg, base text |
| hint label once partly typed | green bg |
| element wash under a hint | mauve @ 25% |
| URLs in completions | blue |
| excmd names | green |
| private-window indicator | red border |
| `/` search matches | yellow, active match green |

Variable names come from Tridactyl 1.25.1's own `static/css/*.css` and
`themes/default/default.css`; anything not set here falls back to the default.

**Element highlights are deliberately off.** Tridactyl's default paints a yellow
25% fill and a brown outline over *every* hintable element the moment you press
`f`. On a dense page that buries the content, and on a text input it floods the
field so you cannot read it. Here only the active element gets a marker — a 2px
lavender outline — and the labels do the rest of the work. The knobs are
`--tridactyl-hint-highlight-{bg,outline,active-bg,active-outline,opacity}`.
